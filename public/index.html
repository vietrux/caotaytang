CAOTAYTANG — Multi-vhost TLS Proxy + CDN Scrubber

Node reverse proxy that maps Host headers to upstream origins and strips Cloudflare / CDN fingerprints from headers, cookies, and HTML/JS bodies.

Quick start

# 1. add wildcard DNS — dnsmasq
sudo apt install dnsmasq
echo 'address=/own_lab.htb/127.0.0.1' | sudo tee /etc/dnsmasq.d/lab.conf
sudo systemctl restart dnsmasq

# 2. cert with wildcard SAN
cd certs
openssl req -x509 -newkey rsa:2048 -nodes -days 825 \
  -keyout mylab.key -out mylab.crt \
  -subj "/CN=own_lab.htb" \
  -addext "subjectAltName=DNS:own_lab.htb,DNS:*.own_lab.htb"

# 3. run
PORT=8765 ADMIN_PORT=9000 node proxy.js

# 4. add route via dashboard
open http://127.0.0.1:9000

Vhost Routes

Host header → upstream URL. Exact match wins, then longest *.suffix wildcard. Adding a route auto-generates body URL-rewrite patterns (see Scrubbing tab → Auto-generated).

Body Scrubbing

When off, only headers + cookies are scrubbed. Body passes through untouched.

Strip Response Headers

Strip Set-Cookie Names

Body Replacement Patterns

Per-group regex replacements. Auto-generated route rewrites are appended automatically (read-only preview at bottom).

Auto-generated Route Rewrites live

Built from current routes + proxy port. Rebuilds on every save. Each route produces 4 patterns covering: scheme://host, //host, unicode-escaped //, and bare hostname.
